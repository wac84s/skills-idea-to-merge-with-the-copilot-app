# Mona's Bookmark Manager Roadmap

> A focused plan for making saved links easier to find, organize, and protect.

| Area | Item | Type | Priority |
|---|---|---|---|
| Discovery | Search & filter bookmarks | 🚀 | High |
| Editing | Edit a bookmark | 🚀 | Medium |
| Organization | Tags or folders | 🚀 | Medium |
| Portability | Import & export bookmarks | 🚀 | Medium |
| Reliability | Duplicate slugs on re-add | 🐞 | Medium |
| Validation | Empty-URL validation | 🐞 | High |
| Data safety | Bookmarks lost when localStorage is cleared | 🐞 | Medium |

## 🚀 Planned features

- 🔖 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: medium
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs on re-add — priority: medium
- 🐞 Empty-URL validation is missing — priority: high
- 🐞 Bookmarks can be lost when localStorage is cleared — priority: medium
